# Lordina Foundation App

Monorepo for the Lordina Foundation cross-platform application.

This repository contains three main workspaces:

- backend/  — NestJS REST API, Prisma ORM, PostgreSQL
- admin/    — Next.js + Material UI administration dashboard
- mobile/   — Flutter application (Android & Windows)

See docs/ for setup and development guides.

This repository is generated as the initial project skeleton. Fill in environment variables and follow module READMEs to continue implementation.
